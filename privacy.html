젤리팝 개인정보처리방침

시행일: 2026년 10월 9일

이나은(이하 "운영자")은 모바일·웹 퍼즐 게임 "젤리팝"(이하 "서비스")을 제공하며, 이용자의 개인정보를 소중하게 다룹니다. 이 방침은 서비스에서 어떤 정보를 수집하고 어떻게 사용·보관·삭제하는지 설명합니다.

1. 수집하는 정보와 목적

구분수집 항목목적
게스트로 이용할 때수집하지 않아요. 게임 진행(단계, 코인, 아이템 등)과 소리 설정은 이용자 기기 안에만 저장돼요.게임 진행 저장
구글 계정으로 로그인할 때구글 계정의 고유 식별값, 이름(표시 이름), 이메일 주소, 게임 진행 데이터(단계, 별, 코인, 하트, 아이템, 털실방 꾸미기, 출석·룰렛·이벤트 기록)로그인 확인, 기기를 바꿔도 이어서 하기
결제할 때 (향후)상품 구매 내역(상품 ID, 구매 확인 정보). 카드 번호 등 결제 수단 정보는 운영자가 받지 않으며 Google Play가 처리해요.구매 상품 지급, 구매 복원

서비스는 광고를 보여 주지 않고, 이용자 행동을 분석하는 도구(분석·추적)를 사용하지 않아요. 이용자의 위치, 연락처, 사진 등에는 접근하지 않아요.

2. 보관 기간과 삭제

  • 로그인한 이용자의 정보는 계정을 삭제할 때까지 보관하고, 삭제하면 지체 없이 파기해요.
  • 게스트 데이터는 이용자 기기 안에만 있어서, 앱 데이터를 지우거나 앱을 삭제하면 사라져요.
  • 법령에서 보관을 요구하는 정보(결제·거래 기록 등)는 해당 기간 동안 따로 보관해요.

3. 계정과 데이터 삭제 방법

  • 앱 안에서: 설정 → 계정 → "계정 삭제"를 누르면 계정과 클라우드에 저장된 게임 진행 데이터가 삭제돼요. 이 기기에 있는 진행 데이터는 "처음부터 다시 시작"으로 지울 수 있어요.
  • 앱에 들어갈 수 없을 때: 아래 문의 이메일로 로그인에 사용한 구글 계정 이메일과 함께 삭제를 요청해 주세요. 확인 후 지체 없이(영업일 기준 7일 이내) 삭제해요.

4. 개인정보의 제3자 제공과 처리 위탁

운영자는 이용자의 개인정보를 제3자에게 판매하거나 제공하지 않아요. 다만 서비스 제공을 위해 아래 업체의 서비스를 이용해요.

업체내용
Google LLC (Firebase Authentication, Cloud Firestore)구글 로그인 처리, 게임 진행 데이터 저장. 서버는 해외(구글 데이터센터, 서울 지역 우선)에 있을 수 있어요.
Google (Google Fonts)글꼴을 불러올 때 이용자의 IP 주소 등 접속 정보가 구글에 전달될 수 있어요.
Google Play (향후 결제 시)상품 결제와 환불 처리

5. 이용자의 권리

이용자는 언제든지 자신의 개인정보를 확인하고, 정정·삭제를 요청하거나 처리 정지를 요구할 수 있어요. 로그인 없이 게스트로 이용하면 어떤 정보도 운영자에게 전달되지 않아요.

6. 아동의 개인정보

서비스는 만 14세 미만 아동에게 개인정보를 요구하지 않아요. 만 14세 미만 이용자는 구글 로그인 없이 게스트로 이용해 주세요. 법정대리인의 동의 없이 만 14세 미만 아동의 개인정보를 수집한 사실을 알게 되면 즉시 삭제해요.

7. 안전성 확보 조치

  • 로그인한 이용자는 본인의 데이터만 읽고 쓸 수 있도록 접근 규칙을 적용해요.
  • 모든 통신은 암호화(HTTPS)되어 전송돼요.
  • 운영자는 이용자의 비밀번호를 보관하지 않아요(구글 로그인 사용).
